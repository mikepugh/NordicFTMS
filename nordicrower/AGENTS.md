# NordicRower

Keep public documentation, release notes, packaged guides and app copy concise
and focused on installing and using NordicRower. Omit customer correspondence,
individual equipment stories, research history, diagnostic evidence and test
results. Refer to other fitness apps generically in setup instructions.

Build instructions, investigation notes and verification details belong in
developer documentation and must not be included in release packages.

Preserve required third-party license notices. Keep changes scoped to NordicRower;
NordicFTMS's application and release workflow are independent.
